## 📖 About

This repository contains my notes and learning documentation from the **AWS Cloud Practitioner Essentials** course.

The course introduces the fundamentals of cloud computing and AWS, covering core services, infrastructure, security, networking, storage, databases, pricing, migration, and cloud architecture.

Each module has its own folder containing **learning notes and a screenshot** documenting the completed module.
